# 我的房屋记录

手机端个人房屋租赁资料记录工具。项目只有 `index.html`、`style.css`、`app.js` 和本文件，无构建步骤。

## 上传到 GitHub

1. 在 GitHub 新建仓库，例如 `rental-record`。
2. 把四个文件上传到仓库根目录并提交。请不要把真实租户资料或证件照片放进仓库。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等 Pages 发布后，在手机浏览器打开 `https://你的用户名.github.io/rental-record/`。如果使用 `你的用户名.github.io` 作为仓库名，网址为 `https://你的用户名.github.io/`。

## 添加到主屏幕

- iPhone：用 Safari 打开网址，点分享按钮，选择“添加到主屏幕”。
- Android：用 Chrome 打开网址，点右上角菜单，选择“添加到主屏幕”或“安装应用”（实际文字随系统版本而变）。

## 数据与隐私

GitHub Pages 网址本身是公开的，并不是私人网站；任何知道网址的人都能打开空白工具。输入的文字只写入当前浏览器的 `localStorage`，不会提交给 GitHub、服务器或第三方服务。其他设备或其他浏览器有各自独立的空白记录。证件图片只在当前页面会话中读取并预览，可进入本次导出的 PNG；刷新或关闭页面后需要重新选择。清理浏览器网站数据、无痕模式结束或更换手机可能丢失记录。导出的 PNG 包含实际资料及所选证件图片，请自行妥善保管。合同“打开”按钮会访问你填写的外部链接。

页面一次记录一套房屋资料。导出生成单张、宽 1080 像素、高度随内容变化的 PNG。
